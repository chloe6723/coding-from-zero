# Coding From Zero｜从零开始学编程

你好，我是一名从零开始学习编程的商科学生。

这个仓库记录我用一年时间学习代码、完成小项目和建立技术思维的全过程。这里会保留每天的学习日志、知识笔记、练习作品，以及学习过程中遇到的问题和解决方法。

我不追求一开始就写出完美的代码，更希望诚实地记录自己如何从“完全不会”一步步走向“能够独立做出东西”。

## 我的目标

- 养成持续学习和复盘的习惯
- 掌握编程与计算机科学的基础知识
- 用代码解决真实的小问题
- 在一年内完成一组可以公开展示的项目
- 探索商业知识与技术能力如何结合

## 记录原则

1. 尽量每天留下真实、简短的记录。
2. 不隐藏错误，记录问题是如何被发现和解决的。
3. 每学到一个概念，尽量用自己的语言解释。
4. 每完成一个阶段，做一次回顾并调整下一步计划。
