# Day 2：学习创建个人 Skill 和开源分享

日期：2026-09-01

## 今天学习了什么

- 了解如何把一项重复工作总结成可以复用的 Skill
- 认识了 Skill 的标准入口文件 `SKILL.md`
- 了解开源项目需要 README、LICENSE、示例和清楚的使用说明
- 学习如何通过 GitHub 分享项目并持续维护

## 今天完成了什么

- 整理了小红书教程《如何创建个人 Skill 并成为开源项目分享者》
- 在 `notes` 中建立独立的 Skill 学习知识卡片
- 把教程中的旧文件结构修正为当前推荐的 Skill 文件夹结构
- 将笔记提交并同步到了 GitHub

## 今天的理解

Skill 就是把自己做事的方法写成一套清楚、可重复执行的规则。开源不只是上传文件，还要让别人看得懂、装得上、用得起来，并愿意继续反馈和改进。

## 遇到的问题

- 教程中的 `skills/skill-name.md` 与当前推荐结构不同
- 需要区分每日学习日志和按主题整理的长期笔记

## 如何解决

- 使用“一个 Skill 一个文件夹，并以 `SKILL.md` 为入口”的结构
- 每日经历写进 `daily-logs`，专题知识写进 `notes`

## 下一步准备做什么

- 选择一个自己经常重复完成的小任务
- 创建第一个真正可以运行和测试的个人 Skill
- 为 Skill 补充使用示例和测试记录

## 今日一句话

把自己的方法写清楚，它就有机会成为别人也能使用的工具。
