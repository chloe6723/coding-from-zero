# Day 1：建立我的第一个 GitHub 项目

日期：2026-08-25

## 今天学习了什么

- 认识了 Git 和 GitHub 的基本用途
- 了解了代码仓库可以保存项目及其修改历史
- 学会用 Markdown 组织一篇学习记录

## 今天完成了什么

- 创建了自己的第一个代码学习仓库 `coding-from-zero`
- 确定把它作为未来一年的公开学习日记
- 建立了日志、笔记、项目和进度目录

## 今天的理解

Git 可以帮助我记录文件每一次有意义的变化，GitHub 则可以在线保存和展示这些记录。即使现在还不会写很多代码，持续留下学习过程本身也是一种积累。

## 遇到的问题

- 需要逐渐熟悉仓库、提交（commit）和推送（push）等概念
- 需要建立适合自己的每日记录习惯

## 明天准备做什么

- 学习 Git 的基础操作
- 认识命令行
- 完成一次小修改并提交到仓库

## 今日一句话

先开始，再慢慢变好。
